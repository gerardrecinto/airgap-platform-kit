The air-gap path

From a connected laptop to a baselined RKE2 node.

Only a file transfer connects the two sides. The animation walks the seven steps in order, and every step is also numbered and described.

Connected side

  1. 1

    List and create

    images.txt goes into airgap_bundle.py create. skopeo copies each image to an OCI directory.

  2. 2

    Bundle with checksums

    manifest.json holds the sha256 of every file. Output is bundle.tar plus its sha256. RKE2 release files and sha256sum-amd64.txt travel alongside.

3

Transfer

Media or a one-way transfer. Record the tarball sha256 somewhere that does not travel on the same media.

Disconnected side

  1. 4

    Verify

    airgap_bundle.py verify fails on a missing, modified or unexpected file.

  2. 5

    Load into the private registry

    load verifies first, then pushes with skopeo to <registry>/<repo>:<tag>. The README targets Harbor.

  3. 6

    Puppet baseline

    The Ansible airgap role stages files, then runs puppet apply for stig_baseline with the rke2_node Hiera role.

  4. 7

    RKE2 install

    rke2-airgap-install.sh checks every file against sha256sum-amd64.txt. registries.yaml points mirrors at the registry.

Then helm upgrade --install platform helm/umbrella -f helm/umbrella/values-airgap.yaml -n apps. global.imageRegistry repoints every image at the private registry.

Order on the node follows the Ansible role: stage, Puppet baseline, then RKE2 install. The bundle checksum is integrity protection against corruption and casual tampering, not a signature.

What is in the repo

Five pieces that fit together.

Puppet baseline

stig_baseline covers sshd, auditd, faillock and pwquality, sysctl, account file permissions and the login banner. Each area has a manage_* switch. 53 rspec-puppet examples check the rendered config.

Hiera role data

Module data holds the defaults. Site Hiera selects a role with the stig_role fact. The rke2_node role keeps IPv4 forwarding on and is documented as an exception.

Hardened Helm chart

Non-root, seccomp RuntimeDefault, all capabilities dropped, read-only root filesystem, a NetworkPolicy template, and a values.schema.json that rejects a writable rootfs.

Umbrella chart

values-airgap.yaml sets global.imageRegistry. helm/validate.sh fails if any rendered image is outside the private registry.

Bundle tool

airgap_bundle.py creates, verifies and loads image bundles with skopeo into OCI layouts and a sha256 manifest. load pushes nothing when verification fails, and --dry-run needs no network.

Offline RKE2 install

rke2-airgap-install.sh installs from a staged directory, checks every file against the release checksums first, handles server and agent nodes, and has a dry run.

Ansible role

The airgap role stages the bundle, scripts and Puppet code, applies the baseline, installs RKE2 and writes registries.yaml. Secrets such as the join token come from Ansible Vault or your store.

CI

GitHub Actions runs Puppet, Helm, scripts, Ansible and Trivy jobs. A GitLab pipeline is included.

Documented exception

RKE2 nodes forward pod traffic, so net.ipv4.ip_forward must be 1. The rke2_node role data sets it, and the Ansible role applies that role by default. That is a deliberate deviation from RHEL-09-253075 and needs an entry in your own exception register.

Scope and claims

What this is, and is not.

The Puppet module implements a small subset of RHEL 9 STIG-aligned settings. It is aligned to those controls, not compliant, certified, or accredited. This project makes no DoD, clearance, or customer claims. Replace the placeholder banner text and review every setting before using it anywhere real.
